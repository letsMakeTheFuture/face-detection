# Face Detection 

A simple real-time **face and eye detection** prototype built with **Python and OpenCV Haar Cascades**.

### Features

* Real-time face detection
* Eye detection
* Webcam-based processing
* Visual bounding boxes

### Technologies

**Python · OpenCV · Haar Cascades**

### Purpose

An introductory computer-vision experiment developed as an early step toward the **EYRA** eye-control project.
